Что делает программа: Позволяет играть в текстовое приключение в мире майнкрафт
Как запустить: python main.py
Что улучшил(а) бы дальше: добавил бы возможность пройти майнкрафт и поправил бы баланс (но скорее всего начал бы делать новую игру на юнити)

Обработанные граничные сценарии:
1) Ввод буквы вместо количества строк перед игрой -> ошибка отлавливается через try
2) Неправильный ввод в меню -> добавлена проверка str.isdigit(input_)

Основной сценарий использования / Инструкция по эксплуатации по этапно:
1) Запускаем игру командой python main.py
2) Выбираем число строк между менюшками игры, в зависимости от размера окна терминала, и того хотите ли вы видеть предидущие менюшки
3) Выбираем код действия в менюшках и нажимаем Enter для продолжения.
4) Повторяем пока не умрем в шахте (цель набрать как можно более большой уровень - он покажется после смерти или в меню статуса)

Замечания:
1) Баланс сделан на скорую руку и может не соответствовать оригиналу
2) Вы не можете крафтить броню на замену новой (она на всегда)
3) При крафте меча он автоматически экиперуется (смысла от второго меча нету если он такой же)
4) При повышения уровня сложность возрастает (каждый 10 уровень)
5) Максимальный уровень достигнутый при тестировании - 68
